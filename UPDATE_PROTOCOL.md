# V1.1 Update Protocol
latest.json:
{
  "versionCode": 12,
  "versionName": "1.2.0",
  "apkUrl": "https://YOUR-DOMAIN/GPSRateMonitor-1.2.0.apk",
  "sha256": "64-character SHA-256",
  "mandatory": false,
  "releaseNotes": ["ปรับปรุง GPS", "แก้ไขความเสถียร"]
}
The hash must match the exact APK hosted. Use HTTPS. Installation is handed to Android Package Installer; no silent install.
